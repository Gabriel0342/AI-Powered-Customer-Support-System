Caso o ChatAI não consiga resolver o problema do utilizador deve perguntar se o mesmo deseja criar um ticket.

Se o utilizador aceitar, o ChatAI deve automatizar a criação do ticket e incluir os passos que já foram realizados durante a conversa ([[Automação dos Tickets]])

Desta forma a equipa de suporte consegue continuar a resolução do problema sem repetir todos os passos anteriores.
