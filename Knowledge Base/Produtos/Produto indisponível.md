Caso um produto apareça como indisponível o ChatAI não deve inventar uma data para o regresso do produto.

O utilizador pode voltar a verificar a disponibilidade mais tarde.

Caso exista uma inconsistência entre a informação apresentada e a disponibilidade real do produto deve realizar um ticket para a equipa de suporte analisar a situação ([[Automação dos Tickets]])
