Caso um produto que o utilizador procura não apareça:

1. Confirmar se o nome utilizado na pesquisa está correto.
2. Tentar pesquisar utilizando menos palavras ou uma parte do nome do produto.
3. Atualizar a página e repetir a pesquisa.
4. Caso o produto devesse estar disponível mas continue sem aparecer deve realizar um ticket.
5. O ChatAI pode automatizar a criação do ticket ([[Automação dos Tickets]])
