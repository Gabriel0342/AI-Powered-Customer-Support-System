Quando o sistema de AI detetar que o cliente tem um problema relacionado com uma entrega deve analisar os seguintes titulos e, quando encontrar o titulo correto analisar o ficheiro em causa:

1. [[Encomenda atrasada]]
2. [[Encomenda marcada como entregue mas não recebida]]
3. [[Morada de entrega incorreta]]
4. [[Encomenda incompleta]]
5. [[Produto chegou danificado]]
